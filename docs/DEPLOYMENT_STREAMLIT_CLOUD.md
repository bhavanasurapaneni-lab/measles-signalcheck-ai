# Free public demo on Streamlit Community Cloud: plan (NOT deployed)

*Prepared in Milestone 9. Nothing has been deployed. Deploy only with the owner's approval.*

## 1. Feasibility
**Feasible**, with one open risk (§5): the app needs no API key, no secrets and no paid services. It runs from
`app/streamlit_app.py` with the pinned `requirements.txt`.

## 2. How the demo gets its data
The DATASUS TabNet exports are **not committed** to GitHub. I found no explicit reuse licence for TabNet
exports: the Ministry's open-data portal states CC BY-ND 3.0, while its open-data plans describe CC BY with
attribution. So the repository does not redistribute the raw files.

Instead, the hosted app shows a **"Download the public data from DATASUS TabNet"** button when the data is missing.
The button runs the repository's own `scripts/fetch_tabnet.py` and `scripts/fetch_health_regions.py`. These
download the same public, aggregate, municipality × year tables directly from the official source
(`http://tabnet.datasus.gov.br`), save them unchanged with SHA-256 manifests, and the connector then validates them.

- **Download safeguards (tested):** only `tabnet.datasus.gov.br` is contacted, including after redirects. Responses that aren't TabNet tables (e.g. HTML error pages) are rejected before anything is saved. All files are written only after every query succeeds. An existing snapshot is never replaced unless `--force` is passed (the app never passes it). The connector then validates codes, years and hashes.
- **Size:** about 23 KB of tables plus a 2.1 MB form page (health-region list).
- **Storage:** Community Cloud storage is temporary, so after a restart the button may be needed again.
- **No personal data** is involved. **No Anthropic API** is contacted.

## 3. Safety properties (implemented and tested)
| Requirement | How it is met |
|---|---|
| Zero Anthropic API calls | `app/streamlit_app.py` never imports the API client (tested). No key is configured. The live switch is disabled unless a key exists **and** `SIGNALCHECK_ENABLE_LIVE=1` |
| No API key required | Nothing reads secrets. **Do not add `ANTHROPIC_API_KEY` to the app's Secrets** |
| Real data or labelled fixtures | Figures come from verified DATASUS data. Demo briefs carry the "NOT generated by Claude" banner |
| Live Claude clearly not enabled | Notice on the main page ("Live Claude generation is not enabled; no Anthropic API calls are made"), sidebar banner, disabled switch |
| Missing data handled gracefully | Download offer instead of a crash. Altered files are refused (tested) |
| No credentials or private files exposed | `.env`, `.venv`, raw data and `.claude/` are git-ignored, so they are never in the deployed repo. The app serves only computed aggregates |

## 5. Risks and platform notes
- **Unverified:** whether TabNet (Brazil) responds to requests from Community Cloud's US-hosted servers. If it doesn't, the download fails with a clear message, and the fallback is to decide (with the owner) whether committing the small aggregate snapshot is acceptable under the data terms.
- **TabNet uses plain HTTP.** Files are hash-recorded on download, but HTTP itself is not authenticated.
- **Platform overrides** (Streamlit docs): Community Cloud forces `browser.gatherUsageStats = true` and `client.showErrorDetails = false`, among others, so Streamlit collects usage statistics on the hosted demo.
- **Network binding:** the hosted platform must bind its own interface. That's why `server.address` is not set in `.streamlit/config.toml`; local runs use `--server.address localhost` instead.
- Apps on the free tier can **sleep** when idle. The first visitor may wait for a restart and a re-download.
- Anyone with the link can press the download button, but it only appears when the data is missing, and it fetches about 2 MB from the official public source.
