# Screenshot guidance

Screenshots are **not committed yet**. Capture them from your own local run so they show real output.

1. Launch the dashboard (`README.md` → *Install and run on Windows*). Use a browser window about 1400 px wide.
2. In the sidebar, set **2019 → 2020**, **All health regions**, municipality **São Gonçalo**.
3. Capture these four views (Windows: `Win + Shift + S`), saving as PNG in this folder:

| File | View | What it should show |
|---|---|---|
| `01_overview.png` | Overview tab | Problem statement, 4 KPI tiles, the statewide trend and the regional bar chart |
| `02_signals.png` | Signals tab | Signal legend, counts chart and the flagged-municipality table |
| `03_trends.png` | Municipality trends (São Gonçalo) | Indexed doses vs state; published coverage with the 100% line |
| `04_brief.png` | Investigation brief (São Gonçalo) | Verified observations **and** the yellow "OFFLINE DEMONSTRATION … NOT generated by Claude" banner |

4. Make sure the **offline demonstration banner is visible** in any screenshot that shows a brief. Never crop it out.
5. Add them to the main README under "Demonstration walkthrough", e.g. `![Overview](docs/screenshots/01_overview.png)`.
