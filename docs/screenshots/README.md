## Re-capturing
1. Start the dashboard locally (see the main README).
2. Open each deep link above at `http://localhost:8501`, or capture headlessly. In PowerShell, run this once per view, changing the size, file name and URL:

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --hide-scrollbars `
  --window-size=1440,1500 --virtual-time-budget=30000 --user-data-dir=$env:TEMP\sc-edge `
  --screenshot=$env:TEMP\01_overview.png "http://localhost:8501/?period=2019&tab=Overview"
```

Never crop out the offline-demonstration banner in screenshots that show a brief.
